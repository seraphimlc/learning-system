# 小升初数学私人衔接知识图谱 v2

## 这版解决什么问题
- 不是小学全量复习表，而是“七上学习所需前置 + 七上主线 + 错因回退”的数据底座。
- 每个节点都能服务四件事：诊断、讲解、出题、复测。
- 暑假只有约50天、每天约1小时，所以节点分成 core、selective_core、diagnose_only、controlled_extension。
- 钟表角、工程题这类拔高题不删除，但只作为受控拓展，不能抢主线时间。

## 暑假必须节点
- `M-BRIDGE-SOLUTION-HABIT` 解题步骤与检验习惯：数学不是只要答案，稳定得分靠步骤、单位、符号和检验。
- `M-PRE-DECIMAL-OPS` 小数运算：小数运算本质上先按整数算，再处理小数点。
- `M-PRE-INTEGER-OPS` 整数四则计算：整数计算是后面所有代数运算的底层肌肉。
- `M-PRE-NUMBER-SENSE` 数感与估算：先判断答案大概范围，防止算出离谱结果。
- `M-PRE-ORDER-OPS` 四则混合运算与括号：算式有交通规则：括号优先，先乘除后加减，同级从左到右。
- `M-PRE-FRACTION-MEANING` 分数意义与单位1：分数不是两个数叠在一起，而是‘把单位1平均分后取几份’。
- `M-PRE-FRACTION-OPS` 分数运算：分数加减靠通分，分数乘除靠约分和倒数。
- `M-PRE-DISTRIBUTIVE` 运算律与去括号意识：运算律不是为了炫技，而是后面整式去括号和合并的前身。
- `M-PRE-EQUATION-BASIC` 小学简易方程：方程是用等号把未知数和已知条件连接起来。
- `M-PRE-LETTER-EXPR` 用字母表示数：字母是会变化的数，用来表达一类情况。
- `M-PRE-QUANTITY-RELATION` 等量关系与列式：应用题最关键不是算，而是找到两个相等的量。
- `M-BRIDGE-WORD-PROBLEM-READING` 应用题审题流程：应用题先读关系，再列式；不是看到数字就算。
- `M-G7-ABSOLUTE` 绝对值：绝对值是一个数到0的距离，距离永远不为负。
- `M-G7-COMPARE` 有理数大小比较：数轴上右边的数大；两个负数绝对值大的反而小。
- `M-G7-NUMBER-LINE` 数轴：数轴把数变成位置，越往右越大。
- `M-G7-OPPOSITE` 相反数：相反数是在数轴上到0距离相等、方向相反的两个数。
- `M-G7-POS-NEG` 正数和负数：负数不是更小的自然数，而是表示相反意义的量。
- `M-G7-RATIONAL-ADD-SUB` 有理数加减：加减本质是在数轴上移动；减法可以转化为加相反数。
- `M-G7-RATIONAL-CLASSIFY` 有理数分类：有理数包括整数和分数，正负只是另一个分类角度。
- `M-G7-RATIONAL-MIXED` 有理数混合运算：混合运算是小学运算顺序 + 初一符号规则的组合。
- `M-G7-RATIONAL-MUL-DIV` 有理数乘除：乘除先定符号，再算绝对值；除法可转化为乘倒数。
- `M-G7-ALG-EXPR` 代数式：代数式是用数字、字母和运算符号表达数量关系。
- `M-G7-COMBINE-LIKE` 合并同类项：合并同类项只合并系数，字母部分不变。
- `M-G7-EXPR-VALUE` 代数式求值：求值就是把字母换成给定数字，再按运算规则计算。
- `M-G7-LIKE-TERMS` 同类项：同类项看字母和字母指数是否完全相同，和系数无关。
- `M-G7-PARENTHESIS` 去括号：括号前是正号不变，括号前是负号每一项都变号。
- `M-G7-POLY-ADD-SUB` 整式加减：整式加减就是先去括号，再合并同类项。
- `M-G7-EQ-PAREN` 含括号方程：含括号方程先正确去括号，再按基础方程流程解。
- `M-G7-EQ-SOLVE` 解一元一次方程基础：解方程的目标是把未知数单独留下。
- `M-G7-EQ-WORD` 一元一次方程应用题：方程应用题的核心是设未知数、找等量关系、解方程、检验答案。
- `M-G7-EQUALITY-PROP` 等式性质：等式像天平，两边做同样的事，平衡不变。
- `M-G7-EQUATION-CONCEPT` 方程与一元一次方程概念：方程是含未知数的等式；一元一次表示一个未知数且最高次数是1。
- `M-G7-ANGLE` 角的概念与表示：角由两条有公共端点的射线组成，也可以看作旋转形成。
- `M-G7-LINE-RAY-SEGMENT` 直线、射线、线段：直线无端点，射线一个端点，线段两个端点且可度量。

## 选择性核心节点
这些节点不是每天都展开；诊断薄弱、或后续主线用到时再进入专题。
- `M-PRE-PERCENT` 百分数与增长率：百分数本质是以100为标准的分率，关键仍是找单位1。
- `M-PRE-RATIO-PROP` 比、比例与比例思想：比表示两个量的关系，比例表示两个比相等。
- `M-BRIDGE-MOTION-BASIC` 行程基础模型：路程、速度、时间三者互相决定：路程=速度×时间。
- `M-BRIDGE-MOTION-CHASE` 追及与相遇模型：追及看速度差，相遇看速度和；本质是距离差/距离和如何变化。
- `M-BRIDGE-PERCENT-MODEL` 百分数应用模型：百分数应用题仍是比较量、标准量、变化量的关系。
- `M-BRIDGE-PROPORTION-MODEL` 比例应用与对应量表：比例题不是套公式，关键是找出两组对应量，并保持对应关系不乱。
- `M-BRIDGE-SUM-DIFF-MULTIPLE` 和差倍模型：和差倍题本质是把两个量转成同一个‘一倍量’。
- `M-G7-POWER` 乘方：乘方是相同因数连乘，底数和指数必须看清。
- `M-G7-SCI-NOTATION-APPROX` 科学记数法与近似数：科学记数法是把很大或很小的数写成a×10ⁿ，近似数要看精确到哪一位。
- `M-G7-MONOMIAL` 单项式：单项式是数字和字母乘积组成的一项。
- `M-G7-POLYNOMIAL` 多项式：多项式是几个单项式的和，每个部分叫一项。
- `M-G7-EQ-DENOM` 含分母方程：去分母是为了把分数方程变成整数方程，但每一项都要乘最小公倍数。
- `M-G7-ANGLE-CALC` 角度计算：角度计算和线段计算一样，抓整体与部分、相等与互补互余关系。
- `M-G7-GEO-SOLID-PLANE` 立体图形与平面图形：复杂图形可以从点、线、面、体这些基本元素看。
- `M-G7-POINT-LINE-PLANE` 点线面体：体由面围成，面与面相交成线，线与线相交成点。
- `M-G7-SEGMENT-MEASURE` 线段比较与计算：线段计算本质是部分与整体的关系。
- `M-PRE-ANGLE-BASIC` 角度基础：角是旋转的大小，一圈360度。
- `M-PRE-UNIT-CONVERSION` 单位换算：单位不统一，公式再对也会错。

## 八条主依赖链
- 分数到方程去分母：分数意义与单位1 → 分数运算 → 有理数乘除 → 有理数混合运算 → 含分母方程
- 等量关系到方程应用题：等量关系与列式 → 小学简易方程 → 等式性质 → 解一元一次方程基础 → 一元一次方程应用题
- 运算律到整式加减：运算律与去括号意识 → 去括号 → 合并同类项 → 整式加减
- 数轴到有理数运算：数轴 → 相反数 → 绝对值 → 有理数大小比较 → 有理数加减
- 文字关系到代数式：等量关系与列式 → 用字母表示数 → 代数式 → 代数式求值
- 行程到钟表角拓展：行程基础模型 → 追及与相遇模型 → 钟表角问题 → 角度计算
- 单位到几何度量：单位换算 → 直线、射线、线段 → 线段比较与计算 → 角的概念与表示 → 角度计算
- 步骤习惯到稳定得分：解题步骤与检验习惯 → 有理数混合运算 → 解一元一次方程基础 → 一元一次方程应用题

## 诊断状态
- A 已掌握：正确率≥85%，能讲清方法，能做小变式；只做间隔复测。
- B 不稳定：正确率60%-85%，或需要提醒；安排微课和少量变式。
- C 薄弱：正确率<60%，或概念说不清；回退前置节点补。
- D 卡死：前置链条也错；暂停当前七上内容，补最早断点。

## 使用原则
- 先诊断再排课，不能凭感觉说孩子哪里弱。
- 七上题错了先查前置链，不直接刷同类七上题。
- 小学计算只做维护和补漏洞，不单独拖成一周专题。
- 每次学习只攻一个主模型，最多配三到五道高质量变式。
- 所有错题必须归因到节点和错因标签，不能只写“粗心”。
- 拓展题服务理解边界，不服务炫技；基础不稳时不做难题堆叠。
