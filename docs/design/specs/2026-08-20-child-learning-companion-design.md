## 0. 定位与设计原则

**定位**：一个孩子初中三年的私人学习陪伴系统。不是平台，不是产品化用户体系——是"儿子的私人助教 + 爸爸的信任"。

**两个用户**：

| 用户 | 使用频率 | 他要什么 |
|---|---|---|
| 儿子 | 假期每天 60 分钟 / 学期每天 20-30 分钟 | 学得动、看得见进步、不被烦 |
| 爸爸 | **每周 10 分钟决策时间**（周信）+ 每天 5-10 分钟**陪看**（亲子互动，见 §6.3） | 放心、知道下一步 |

**设计判据（一切取舍以此为准）**：任何机制，如果不能让"儿子这周学得更好"或"爸爸这周更放心"，就不配存在。

**设计原则**：

1. **私人助教思维，不是平台思维**：没有平台包袱，大胆做减法。
2. **YAGNI**：数据模型为三年立骨架，功能只做七上数学。骨架是"接口"，功能是"实现"，接口现在定，实现按需长。
3. **可复现判定**：掌握状态判定必须代码可算（可测试、可追溯）。判定错了污染三年档案，不能靠概率。
4. **档案只增不改（append-only），计划可重排**：孩子学过的痕迹是神圣的，计划错了可以推翻重来。
5. **爸爸是最终拍板人**：爸爸非教育背景，专家负责提案，爸爸凭对儿子的了解做最终决定（§5.4 审核机制）。

**执行窗口（本稿日期 2026-08-20，距 2026-08-24 开学 4 天）**：假期活动（诊断建档、Tier 二轮复核）**挂下一假期或压缩执行**；本切片交付范围为**学期模式数据链路**（判定口径统一、错题录入、周信），开学首月即用。收口验收与建档活动的时序冲突按 §8.1 执行。

## 1. 用户与价值

### 1.1 儿子的价值

- 每天有一件"看得见自己进步"的事：节点点亮、状态变化、错因模式的"终于不再错"。
- 不是被系统安排的机器：每周自选目标、卡住时可以选动作（已有雏形）。
- 节奏贴合初中课业现实：学期模式低强度日常 + 周末主线。

### 1.2 爸爸的价值

- 每周 10 分钟看懂孩子：周信回答三个问题——这周学了什么？掌握状态如何？下周该盯什么？
- 学期末有学期报告（先做周信聚合模板，三年叙事只留接口）。
- 三年后有一份成长叙事：这是"陪伴"区别于"项目"的产品内核。

### 1.3 爸爸的角色定位

爸爸是：问题的提出者、一小部分的产品设计者、用户之一，**但非教育背景**。

- 爸爸**不负责**：教研内容、认知设计、测量判定——交给专家面板（§5）。
- 爸爸**负责**：拍板。所有专家提案必须带"三件套"（一句话结论 / 核心依据 / 备选与代价），爸爸读完三行，凭对儿子的了解说 yes/no/改。
- 不可替代性：**爸爸是唯一懂这个孩子的人**。

## 2. 节奏模式

| 模式 | 时段 | 日/周结构 | 目标 |
|---|---|---|---|
| **假期模式** | 寒暑假衔接 | 每天 60 分钟：旧错复测(5) → 讲本质/模型(15) → 变式题(25) → 错因回退(10) → 记明日复测(5)；**诊断建档在假期头 1-3 天单独进行**（不占日模板） | 主线推进 + Tier S 前置按需建档（见 §4.3） |
| **学期模式** | 开学期间 | 平日每天 20-30 分钟：作业/考试错题录入 + 回查 2-3 道针对性题；周末 60 分钟：主线推进 + 下周目标自选 | 档案持续更新 + 主线慢推 |
| **考试复习模式** | 月考/期中/期末前一周 | 自动切换：全链回查 + 综合检测 | 全链薄弱点暴露与回炉 |

**原则**：学期模式下"档案不中断"比"每天学得多"更重要。低强度日常保证数据连续，周末主线保证推进。

**防过度诊断闸门（知几，硬约束）**：

1. 单节点单次诊断题量上限（默认 5 题，超限转主线）；
2. 回查深度上限（默认 3 层，超过则只查 C/D 状态节点，不无限展开）；
3. 回退触发需连续确认：**同节点连续 3 次 C/D 判定**才触发回查（与 §6.1 卡住阈值同一口径；**依赖 M2.5 判定口径裁定后复核**——若统一后状态货币变化，"连续 3 次 C/D"的定义随之漂移）。

## 3. 评估与档案链路（三年陪伴的心脏）

### 3.1 错题录入

- **方案**：错题录入（选节点 → 选错因 → 记录）+ 系统内做题自动记录。
- **录入归属（默认，待爸爸确认）**：**孩子用最小表单录入**（节点/错因下拉选择，错因词表对齐现有 `CANONICAL_ERROR_TAGS`，保证三年错因分布可比）；**爸爸只做两件事**——周信确认 + 低置信错因的确认。理由：爸爸做录入会突破每周 10 分钟决策预算并制造 §6.3 要避免的监视感；孩子做自我诊断有认知价值，且最小表单不违反"孩子页面简单"。
- **证据载体（第 0 步核对必答项）**：手动录入意图复用 `attempts` 表（`answer_source='parent_manual'`），但 `attempts.question_id` / `session_id` 均为 **NOT NULL 外键**（已核实 db.py L419-421），作业错题无题库题、不属于学习会话。**必须裁定方案**：① 放宽/可空化这两列（含联动索引）；② 合成占位 question/session（污染题库与统计，不推荐）；③ 旁挂侧表再反链。裁定后才断言证据链一致。
- **判定语义（归 `mastery_criteria_proposal` 裁定）**：手动录入的作答结果由**孩子自报对错 + 爸爸确认**；`explanation_score` 天然缺失（自我诊断不产出解释分）——若裁定口径要求 can_explain 证据（evolution.py 现状），需定义手动证据入档规则（如：手动证据只作 C/D 下探与复测触发，不作 A 档升档依据），否则学期模式的数据输入永远进不了高置信档。
- **选择偏差处理**：增加可选"作业全对"确认（每日一键），**只作证据范围标注，不进判定样本**；周信/双周简报**必须标注证据范围**（仅系统内 / 含手动补录 / 含全对确认）。"全对确认"的存储载体列为第 0 步核对必答项。
- **明确不做**：OCR（题面识别 + 归节点都不可靠，YAGNI；将来手动录入成为负担再评估）。

### 3.2 评估方式（A/B/C/D 如何更新）

**原则（本稿定）**：

1. 状态判定**代码可复现**：阈值、规则、证据链可测试、可追溯。
2. **最小证据量 + 间隔复测确认**：单次波动（如 3 题 2 对）不得直接改三年档案；升降级需满足最小样本与复测确认条件。
3. LLM 只在两处：① 错因归类（信任边界见下）；② 周信/学期报告的叙述生成。

**现状（已核实）**：判定口径**至少 3 套并存**——蓝图 §12（85%/60-85%/<60%）、`evolution.py`（0.85/0.60 + can_explain + 最小样本）、`flow_nodes._mastery_diagnosis`（stable/likely_stable/emerging/insufficient_evidence + 0.6 边界 + 迁移证据）、`daily_runtime` v51（mastery_recommendation → status_code 映射）。**第 0 步逐实现核对，全部收口为一套**。

**归属**：具体判定规则（阈值、最小证据量、时间窗口、升降级、复测间隔算法）由**权衡产出 `mastery_criteria_proposal`**——**已产出并于 2026-08-20 经爸爸拍板通过**（见 `docs/design/specs/2026-08-20-mastery-criteria-proposal.md`，含 T1-T23 可测试锚点）；落地为代码见 M2.5（§8.4），实现等 evolution/daily_runtime 并行改动落定后进行。本稿不预写规则。

**LLM 错因归类信任边界**：错因归类是 LLM 输出，流入错因分布 → 周信 → 简报 → 教学决策。边界：

- 归类低置信（模型自评 < 阈值）→ 标注"待爸爸确认"，不计入错因统计；
- 爸爸确认或规则命中（可复现归因）才计入分布。

### 3.3 长期档案与短期计划（数据模型：现状核对 + 只补缺口）

**现状（已核实）**：数据库已存在长期状态与短期计划的分离——`attempts`（作答记录）、`learner_node_status`（节点当前状态 + status_revision）、`mastery_decisions`（append-only 状态变更留痕）、`generated_plans`/`daily_flows`（短期计划）。

**数据模型工作第一步 = 《现状数据流核对》**（切片第 0 步）：逐表对照现状与需求，裁定"新增 vs 别名"。**已裁定新增**（结构细节第 0 步核对）：

- `error_cause_log`（错因三年分布；消费方 §3.2/§6.1 已硬依赖，非可选）；
- `weekly_summary`（周信存档，**长期档案 append-only**，存**当周 A/B/C/D 时间快照** + 爸爸确认状态枚举 acknowledged/unacknowledged）；
- "作业全对"确认载体（只作证据范围标注）。

**计划结构**：`learning_path` 是图谱顶层规划配置 dict（非档案），本次改为**阶段数组**。**先落 2 阶段结构**（暑假衔接收口 + 开学首月），其余枚举（学期周复盘 / 考试复习 / 假期衔接）随学期增长追加——全量枚举与切片落地范围显式区分，落地以切片为准。

## 4. 图谱长期化策略

### 4.1 结构：单文件 + 双层图谱

```
math_knowledge_graph.json（单文件，三年都在这里长）
├── 主线层（Mainline）：年级课程节点（七上 → 七下 → … → 九下）
└── 前置层（Prerequisite）：跨年级依赖（小学前置/桥梁 → 七上 → 未来七下…），只服务回查
```

单文件保证"跨年级整条链"连通（trace_back 已建好）；拆多文件引入跨文件解析新基建。250 节点规模对 JSON 无压力。

### 4.2 现有 56 节点角色重定义

| 节点层 | 数量 | 角色变化 |
|---|---|---|
| 七上主线 | 32 | 暑假预学目标 → **七上学科的正式主线**（语义不变，身份升级） |
| 小学前置 + 桥梁 | 24 | 暑假要补的内容 → **回查用前置层**：不再主动教，只在七上错题回查时按需诊断 |

**变更范围**：节点**内容字段零改动**；仅 `metadata` 增 `subject: math` + `grade: 7`，属 schema 变更——走 **lineage 影响评估**（内容/结构 lineage 分离方案，§10 #4，与本改动同步或先行）。

### 4.3 诊断策略与认知跳跃

**诊断策略**：80 分的孩子不做预防性补差——

- 只做 **Tier S 前置建档**（8 个节点，见评审文档 §5）；建档在**假期头 1-3 天单独时段**（不占日模板）；建档测量设计（题量、跨两天采样）归权衡；
- 其余小学前置**不做预防性诊断**，等七上错题回查时按需触发；
- **前置待办**：评审文档 §7.2 的 Tier 二轮复核需先完成，Tier S 才可作为建档依据（当前窗口无法执行，挂下一假期）；
- 时间预算留给真正的风险：**七年级认知跳跃**。

**认知跳跃机制（归属知几）**：

- **识别信号**：链上**已建档节点全 A**（未建档节点视为不阻塞，因非 Tier S 不做预防性建档）+ 概念题连续错 3 次 → 标记"概念转变"场景。注意：该信号依赖判定口径裁定（M2.5）后复核；
- **教学响应**：冲突情境 / 反例 / 表征转换——**素材待琢玉产出**（修正：蓝图 §8.2 是核心模型，非反例素材；正确出处在蓝图讲法备选清单，且需琢玉补"概念转变响应模板"正式结果与交付时点）；
- 与闸门 #3 的关系：概念题连续错 3 次且链上全 A → 走概念转变路径；链上有 C/D → 走前置回查路径。

### 4.4 学期演化机制

```
每学期末新增下一年级节点：
  教研提案（琢玉）→ 评估审定（权衡）→ 认知审查（知几）→ 爸爸拍板
  → 应用 → graph_contract 契约门禁 → 派生物重生成 → 版本号递增（含 lineage 影响评估）
```

### 4.5 明确不做（YAGNI）

- 不做多学科图谱结构（只留 subject 字段 + registry）
- 不现在做七下内容（只立机制，内容按学期长）
- 不拆分文件

### 5.3 与工程侧 pack（software-development）的关系

### 5.4 三方会审协议

```

   ↓
```

## 6. 产品层输出

### 6.1 周信（一页纸，自动生成）

- 本周覆盖节点 + 状态变化（哪些绿了；附当周 A/B/C/D 快照）
- 错因模式一句话（标注证据范围：仅系统内 / 含手动补录 / **含全对确认**——与 §3.1 三分类一致）
- 下周重点一句话
- 异常提示（**连续 3 次 C/D 判定**，与 §2 闸门 #3 同一口径；依赖 M2.5 裁定后复核）

**失败路径与降级**：

- LLM 叙述生成失败 → 降级为模板填充（覆盖列表 + 状态表，无叙述），不阻塞；
- 爸爸未确认 → `weekly_summary.status='unacknowledged'`，存档不丢，可补看；
- 缺勤/生病/出差 → 跳过该周报告（不补发），档案不中断靠"下次录入时补录窗口"（默认 7 天）。

### 6.2 学期报告（降级版）

首个学期版本 = **周信聚合模板**（覆盖汇总 + 状态演化表 + 错因分布），不依赖 LLM 长叙述；**三年成长叙事只留接口**（内容随档案累积自然长出）。

### 6.3 动机层（成本最低的三件事）

1. 每节课结束"点亮图谱节点"的即时反馈；
2. 每周让孩子从 2 个候选里自选下周目标（自主感）；
3. **爸爸陪看**：每天睡前 5-10 分钟听孩子讲一道题——**亲子互动，不是负担、不是监控**（区别于周信的决策时间）；避免"每天看错误记录"的监视感（知几审查点）。
