## 一句话结论

30 题整体**契合度高、无答案错误、无真正超纲**，但存在三处必须修的问题：**3 道"零的意义"计算题（5−5 / 8×0 / 0÷5）是琐碎算术冒充概念题（偏题+一眼答案）**、**6 道 hard 题难度虚高（hard 档灌水，会虚抬 A 档证据）**、**节点核心错因"除数是小数不会转化"几乎无题可测**；另有两道互化题存在答案形式歧义（孩子写 0.5/7/10 会被判错）。

## 审查要点（5 条）

1. **契合度总体健康，但"零的意义"子技能被 3 道算术题架空**：POS-NEG 的 3 个"零的意义"槽位填了 5−5、8×0、0÷5——孩子答对"0"完全不暴露"0 既不是正数也不是负数"这一核心属性（答案不经过概念判断），属于**偏题（实际测 M-PRE-INTEGER-OPS 的算术事实）+ 一眼答案**。脚本注释显示这三题是为演示 sympy 门禁在概念节点可过而配的 verified 计算题——**为实现目标而选材，与"少而精、优先暴露认知断点"的项目原则相悖**。
2. **hard 档系统性虚高（6 题）**：认知需求仅 medium 的题（如 POS-NEG"温度计 0℃ 以下 15℃"与 easy 档同模板、DECIMAL"3×0.4÷0.2"规则明确三步左到右）被标 hard/L4/transfer。判定层 A 档依赖"hard 复测/迁移证据"（契约 §3、§5），**难度注水会让 A 档证据虚高**，这是比单题标定更严重的结构问题。
3. **节点头号错因"除数是小数不会转化"几乎无题可测**：DECIMAL-OPS 15 题中仅 1 题内嵌一步 ÷0.2，无一道标准小数除法题（如 7.2÷0.8）；"结果不估算"错因 0 题。掌握标准"能解释小数除法为何移动小数点"无从取证。
4. **"记作"模板反射风险（POS-NEG 7/15 同套路）**：温度×3、电梯×2、收支/粮库×2 全是"给定正方向记法 → 求反方向记法"单步模板，直接踩中节点 `avoid`（"同一套路连续刷十几题，孩子会形成模板反射但不一定理解"）。唯一有真实两步推理的是 B5-I0（电梯 8→1 楼）。
5. **元数据与内容错位**：`question_type` 标签按矩阵 offset 轮转（POS-NEG 6 题标签与内容不符，如"识别相反意义"题挂"用正负数表示"）；概念情境题（温度/收支/粮库）机械挂 `visual_spatial` 标签不贴切；DECIMAL 的 L1"识别"档全是直接计算，**L1 识别层级在实质上不存在**。

### 2.1 M-PRE-DECIMAL-OPS

- **B1-I0（3.2+1.7）**：考点=一位小数加法与小数点对齐；难度=锚点题取最简，medium 是"教学锚点难度"非认知难度；阶梯=标准例题（L2 套用基准线）；陷阱=无（锚点题不埋陷阱）；角色=讲本质用——"先按整数算（32+17），再点小数点"的演示载体。
- **B1-I1（0.6×10）**：考点=小数×整十数的位值移动；难度=easy，但内容为规则反射（记忆层）；阶梯=L1 识别应问"判断考点"，此题却是直接计算，**L1 层级名存实亡**；陷阱=小数点移动方向/去尾零；角色=脚手架，可保留但需补真识别题。
- **B1-I2（0.5→1/2）**：考点=一位小数化分数（十分之五）；难度=easy（互化锚点）；阶梯=L1 识别锚点；陷阱=无（锚点）；角色=互化方向的基准示范。
- **B2-I0（5.6−2.3）**：考点=一位小数减法；难度=easy 定位对但内容琐碎（无借位无对齐差）；阶梯=L2 套用；陷阱=**无处可错**——同位数减法不存在"小数点对齐错"；角色=减法脚手架，建议换 5.3−1.8 让对齐错有处可错。
- **B2-I1（1.2×3.5）**：考点=两位×一位→两位小数乘法；难度=medium（整数乘 12×35 + 积位数两步）；阶梯=L2 套用；陷阱=积小数位数（420→4.20→4.2）；角色=乘法标准变式。
- **B2-I2（2/5+0.3）**：考点=分数化小数后加法（互化+加减混合）；难度=medium（需先统一形式）；阶梯=L3 变式（换形式混合）；陷阱=2/5 误读为 2.5、互化后忘对齐；角色=互化-加减桥接题；**需注明输出形式（用小数表示）**。

- **B3-I1（3×0.4÷0.2）**：考点=同级混合运算顺序 + **除数小数转化**；难度=标 hard 虚高，实为 medium（规则明确三步）；阶梯=L4 迁移（混合运算顺序属 M-PRE-ORDER-OPS 前置，迁移成立）；陷阱=÷0.2 不转化直接除（1.2÷0.2 与 3÷0.2 的转化是唯一"除数是小数"考点）；角色=全库唯一除数小数覆盖点，**降 medium 但必须保留**。
- **B3-I2（3/4×0.8）**：考点=分数化小数后乘法；难度=medium~medium偏高（0.75×0.8 积位数计数）；阶梯=L4 迁移（互化+乘双知识，但够不上 hard）；陷阱=积位数（0.600→0.6）；角色=互化-乘法迁移题，降 medium。
- **B4-I0（7.3+2.7）**：考点=一位小数加法（结果整数化）；难度=easy 检测；阶梯=L2 检测；陷阱=10.0→10 的书写规范；角色=掌握档快速检测；区分度低可接受（检测 easy 定位）。
- **B4-I1（0.25×0.4）**：考点=积小数位数+去尾零；难度=**hard 名副其实**（25×4=100→0.100→0.1，三处可错）；阶梯=L3 检测 hard；陷阱=位数错（1 或 0.01）、去尾零遗忘；角色=本节点 hard 标杆，判定层 hard 证据的可靠来源。
- **B4-I2（0.75−1/4）**：考点=小数减分数需统一形式；难度=medium 复测；阶梯=L3 复测；陷阱=1/4 化 0.25 后相减（0.5）；角色=防"会背不会用"复测；**需注明输出形式（用分数表示）**。
- **B5-I0（10−3.75−4.25）**：考点=凑整策略（3.75+4.25=8）；难度=hard 虚高（顺序算不扣分，无错误陷阱）；阶梯=L4 复测策略题；陷阱=策略盲区（看不出凑整），非计算错误；角色=策略性复测；降 medium 或改"用简便方法计算"。
- **B5-I1（0.2×0.3）**：考点=积小数位数；难度=easy 但陷阱密度高（0.6 vs 0.06）；阶梯=L1 诊断（识别位值错因）；陷阱=**0.6 是错的**（位数数错），对应节点"结果不估算"类错因；角色=最佳诊断题，直接区分"会算不会点小数点"。
- **B5-I2（3/20→0.15）**：考点=分数化小数（除数 20 需补位）；难度=medium（3÷20 除不尽心算需补位）；阶梯=L2 诊断；陷阱=1.5（丢零）；角色=互化方向诊断（分数→小数），与 B1-I2 方向互补。

### 2.2 M-G7-POS-NEG

- **B1-I0（温度 +3/−5℃）**：考点=用正负数表示相反意义的量（温度基准）；难度=medium 锚点；阶梯=标准例题（L2 套用基准）；陷阱=无（锚点）；角色=讲解"零上/零下"分界的标准情境；标签建议去掉 visual_spatial。
- **B1-I1（相反意义选择）**：考点=识别"相反意义"（方向相反/收支相反，与数值无关）；难度=easy；阶梯=**L1 识别正宗实现**；陷阱=东/南（方向不同但非相反）、同向不同值（C/D）；角色=概念识别脚手架，本节点最佳 L1。
- **B1-I2（5−5）**：考点=整数减法得 0（**错位：不测 0 的属性**）；难度=easy 但琐碎；阶梯=L1 却无识别任务；陷阱=无；角色=无教学角色（仅演示 sympy 门禁）——**替换**。
- **B2-I0（电梯 +6/−4）**：考点=用正负数表示升降；难度=easy；阶梯=L2 套用；陷阱=方向看反（+4），对应"语境方向看反"；角色=空间方向情境套用；visual_spatial 标签在此成立。
- **B2-I1（收入+500/支出 350）**：考点=用正负数表示收支；难度=medium（与 easy 档同认知，档内区分弱）；阶梯=L2 套用；陷阱=不会用负数表示亏损（节点#2 错因）；角色=收支情境套用；标签建议去掉 visual_spatial。
- **B2-I2（0 的属性判断）**：考点=0 既不是正数也不是负数；难度=medium；阶梯=L3 变式（从"记作"转入属性判断）；陷阱=把 0 当正/负（节点#1 错因）**完美对应**；角色=零的意义核心概念题。
- **B3-I0（说法错误的是 D）**：考点=相反意义量的辨析（含数值无关性）；难度=medium（反向设问+细读）；阶梯=L3 变式（双否定干扰）；陷阱="向北 3 米与向南 5 米不是相反意义"——**数值不同≠不是相反意义**，正中核心迷思；角色=高辨析度变式题。
- **B3-I1（温度计 0℃ 以下 15℃）**：考点=0℃ 分界记负；难度=标 hard/transfer **虚高**（与 easy 档同模板）；阶梯=L4 但无迁移成分；陷阱=0℃ 分界理解（单步）；角色=模板重复题——**换真迁移题或降级**。
- **B3-I2（数轴 0 的位置）**：考点=0 在数轴上的归属（左边负/右边正/0 是分界）；难度=medium 更诚实；阶梯=L4（借用数轴，属解锁节点预告）；陷阱=0 归入正或负；角色=数轴预告+零的意义；**降 medium，教学注释"数轴预告"**。
- **B4-I0（零上 25/零下 10℃）**：考点=温度记负；难度=easy 检测；阶梯=L2 检测；陷阱=无新陷阱；角色=检测易档，**与 B1-I0 重复，建议换情境**。
- **B4-I1（粮库 +30/运出 45）**：考点=运出记负；难度=hard **虚高**（同 B2-I1 模板）；阶梯=L3 检测；陷阱=不会用负数表示运出（节点#2 错因）；角色=检测题，**降 medium，与 B2-I1 去重**。
- **B4-I2（8×0）**：考点=乘法零律（**错位：算术事实，不测 0 的归类**）；难度=medium 琐碎；阶梯=L3 复测无实义；陷阱=无；角色=无——**替换**。
- **B5-I0（电梯 8→1 楼）**：考点=先算楼层差再取负（参照系转换）；难度=hard 基本成立（两步推理）；阶梯=L4 复测；陷阱=只记符号忘算差（+8/−8）；角色=本节点最佳 hard，判定层 hard 证据来源。
- **B5-I1（哪个是负数）**：考点=负数识别（含负小数）；难度=easy；阶梯=L1 诊断正宗实现；陷阱=0 当负数、正数误判；角色=概念诊断题，含 −2.5 破除"负数=负整数"迷思。
- **B5-I2（0÷5）**：考点=除法零律（**错位：同 B1-I2/B4-I2**）；难度=medium 琐碎；阶梯=L2 诊断无实义；陷阱=无；角色=无——**替换**。

## 四、实质问题清单与修订优先级

### P0（阻断，必须改——影响题目有效性或判分正确性）

1. **替换 POS-NEG 三道"零的意义"算术题**（B1-I2 / B4-I2 / B5-I2）：改为真正逼出"0 的属性判断"的概念题，例如："0℃ 表示没有温度吗？为什么？""海拔 0 米表示没有高度吗？""0 是最小的数吗？为什么？"（诊断题建议用"0 是（ ）A. 正数 B. 负数 C. 既不是正数也不是负数 D. 是正数也是负数"）。代价：这 3 题会从 verified 变 unverifiable——**概念节点本来就该以 unverifiable 为主，不应为实现门禁演示而牺牲题效**（契约 §4 允许概念题 unverifiable 入库）。
2. **消除答案形式歧义**：DECIMAL B2-I2、B4-I2 题干注明"用小数表示 / 用分数表示"（或扩展 expected_answer 接受双形式）。依据：判定层以 expected_answer 判对错，形式歧义会产生**系统性误判**（孩子数学正确但被判错）。
3. **补小数除法覆盖**：节点 #2 错因"除数是小数不会转化"全库仅 1 题内嵌；掌握标准"能解释小数除法为何移动小数点"无从取证。补 1-2 道标准小数除法（如 7.2÷0.8、12.6÷0.3），并把"为什么移动小数点"纳入 solution_steps 的解释要求。代价：替换 1-2 道低价值题（如 B4-I0 / B2-I0）。

### P1（重要，影响判定层证据可信度）

4. **难度重新标定（6 题虚高）**：DECIMAL B3-I1、B3-I2、B5-I0 与 POS-NEG B3-I1、B3-I2、B4-I1 由 hard 降为 medium。依据：hard 档是 A 档复测/迁移证据来源（契约 §3、§5），难度注水会**系统性虚抬 A 档**。代价：hard 题数量减少后需补 1-2 道真 hard（DECIMAL 可用多步混合运算、POS-NEG 可用结合分类/数轴的迁移题）。
5. **POS-NEG 换掉 2 道"伪 transfer"**（B3-I1、B4-I1）：无迁移成分却标 transfer/hard，会污染 C3 双角色证据。换为真迁移（如"下列数中，既是负数又是……（结合 M-G7-RATIONAL-CLASSIFY 前置性判断）"），或降为 core medium。
6. **压缩"记作"模板重复（7/15）**：直接触发节点 `avoid`（模板反射条款）。建议合并温度×3、收支×2 为各 1 题，空出的槽位换相反意义辨析/解释题。依据：变式理论——表面情境变化而结构不变，测的是模板记忆而非理解。

### P2（打磨）

7. **L1 识别档空转（DECIMAL 3 题）**：补真识别题（"下面哪道题要先对齐小数点？""0.6×10 与 0.6×100 结果的小数点位置有什么规律？"）。
8. **`question_type` 标签与内容错位（POS-NEG 6 处）**：入库或契约校验时加"标签-内容一致性"检查（B1-I1 内容为识别却挂"用正负数表示"等）。
9. **error_tags 贴切度**：温度/收支/粮库题去掉 `visual_spatial`（无空间元素），保留给电梯/方向/数轴题；概念情境题建议 `concept_confusion`（+建模/读题类）。依据：错因标签是回退链与三年错因分布的锚点（error_tags.py 单一源），错标会污染归因统计。
10. **B3-I0 情境题**：删去已给表达式以测列式，或降为 L2。
11. **"结果不估算"错因 0 题覆盖**：可在一道计算题的 solution_steps 中加入估算步（如 12.5+18.75≈12+19=31），或在教学注释中说明估算作为讲解习惯而非题面要素。
