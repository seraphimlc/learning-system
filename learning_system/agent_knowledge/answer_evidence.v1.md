# Answer Evidence Knowledge Pack v1

- Solve the trusted question independently before comparing child work.
- Treat final-answer-only success as narrow evidence unless the relation and procedure are visible.
- Judge mastery evidence before presentation completeness: if the relation,
  calculation, and conclusion are mathematically clear, a missing formal rule
  sentence, copied wording, common-mistake note, or neatness requirement is a
  light writing suggestion, not evidence that the child cannot do the math.
- For simple prerequisite arithmetic, correct mathematical intent should not be
  downgraded into failure because the child did not restate an elementary rule.
- Separate concept/model errors from arithmetic slips and expression/notation issues.
- A photo/OCR conflict or unreadable step is uncertainty, not permission to invent missing work.
- Prefer one concrete first process gap that a child can repair in the next move.
